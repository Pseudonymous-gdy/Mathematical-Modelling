下面把**问题一**（题目里的第一个子任务）说清楚，并给出一个**能直接落地、且严格符合题设**的“单一核心模型”（后面 B–E 都能复用它的输出）。

---

## 1) 问题一是什么？

题目要求你们：**建立模型，给出每位选手在其参赛的每一周获得的 fan votes（观众投票数）的估计值**；并回答两点：

1. 这些估计是否能导致“每周被淘汰的人”与真实一致（给一致性指标）
2. 你们对这些 fan vote 估计有多确定，这种确定性是否会随选手/周而变化（给确定性指标）

同时题面强调：能导致相同淘汰结果的 fan votes **不唯一**，示例里的票数只是为了构造正确结果的“假设值”。

---

## 2) 我们要用哪些变量？如何从数据得到？

用三层变量：**索引/观测量/未知量（目标）**。

### 2.1 索引

* 赛季 (s\in{1,\dots,34})
* 周 (t\in{1,\dots,T_s})
* 选手（情侣） (i\in \mathcal A_{s,t})（当周仍在赛的集合）

### 2.2 观测量（由 CSV 直接计算）

1. **评委分**
   从 `weekX_judgeY_score` 取分（忽略 `N/A`），当周总分
   [
   J_{i,t}=\sum_{j\in \text{available judges}} \text{score}_{i,t,j}.
   ]
   题面说明：`0` 表示已淘汰后的占位分；`N/A` 代表该周/该评委不存在。

2. **当周评委百分比**（用于 percent 制度）
   [
   P^J_{i,t}=\frac{J_{i,t}}{\sum_{k\in\mathcal A_{s,t}} J_{k,t}}.
   ]
   题面 Appendix 对 percent 的计算就是这么定义的。

3. **当周评委名次**（用于 rank 制度）
   把 (J_{i,t}) 在 (\mathcal A_{s,t}) 内排序得到 (R^J_{i,t}\in{1,\dots,|\mathcal A_{s,t}|})。

4. **真实淘汰结果**
   由 `results` 字段解析每位选手的淘汰周（或名次），即可得到每周被淘汰集合 (\mathcal E_{s,t})。

### 2.3 未知量（问题一要估的“fan votes”）

题设目标是**票数（fan vote totals）**，我们就用：

* (F_{i,t}\ge 0)：选手 (i) 在周 (t) 获得的**观众投票数**（题设量）
* (V_t=\sum_{k\in\mathcal A_{s,t}}F_{k,t})：当周总票数（未知）

关键点：题目示例表明“绝对票数规模”是可任意缩放的，只要相对大小/占比满足淘汰规则即可；因此绝对规模 (V_t) **不可由题给数据唯一识别**。
所以我们引入一个完全等价、但便于推断的表示：
[
p_{i,t}=\frac{F_{i,t}}{V_t},\quad \sum_{i\in\mathcal A_{s,t}}p_{i,t}=1,
]
并最终输出 (F_{i,t}= \hat V_t\cdot p_{i,t}) 的“等比例票数”（例如固定 (\hat V_t=10,\text{million}) 与题面示例同量级，或 (\hat V_t=1) 给出“相对票数”）。这仍然是题设的 fan votes，只是承认其**仅在比例意义下可识别**。

## 3) 如何把这三部分组成一个模型（一个模型解决问题一）

给你一个“单核心、可递增”的**动态贝叶斯模型**：用**人气潜变量**生成 (p_{i,t})，再用题设淘汰规则把 (p_{i,t}) 与观测淘汰 (\mathcal E_{s,t}) 绑定。

### 3.1 人气 → vote share 的生成层（解决“不唯一”并给不确定性）

引入潜在人气状态 (z_{i,t})（越大越受欢迎）：
[
z_{i,1}\sim \mathcal N(\mu_i,\sigma_0^2),\qquad
z_{i,t}=z_{i,t-1}+\epsilon_{i,t},\ \epsilon_{i,t}\sim \mathcal N(0,\sigma_z^2).
]
用 softmax 把人气变成当周 vote share：
[
p_{i,t}=\frac{\exp(z_{i,t})}{\sum_{k\in\mathcal A_{s,t}}\exp(z_{k,t})}.
]
直观含义：票数随周变化但有“惯性”，这正是把“多解”收束成“可解释的一族解”，同时后验方差/区间自然就是题目要的 certainty measure。

### 3.2 规则层：由 (J_{i,t}) 与 (p_{i,t}) 计算“当周风险分”

按题设两种合成方式分别定义“淘汰风险分” (S_{i,t})：

**(A) Percent 制度（season 3–27a）**
[
S_{i,t}=P^J_{i,t}+p_{i,t}.
]
分数越小越危险（示例就是“百分比相加决定淘汰”）。

**(B) Rank 制度（season 1,2,28a–34）**
先对 (p_{i,t}) 排名得 (R^F_{i,t})，再
[
S_{i,t}=R^J_{i,t}+R^F_{i,t}.
]
这里**rank 越大越差**，所以 (S_{i,t}) 越大越危险；题面示例中被淘汰者确实对应更大的“名次和”。

**(C) Season 28 起 bottom-2 + 评委救人（题面允许假设从 28 开始）**
题目说：先用合成结果找 bottom two，再由评委在二者中选一个淘汰。
我们在问题一里不需要建“评委投票细节”，只要把它作为一个合理的概率机制加入似然即可：

* 先由 (S_{i,t}) 找到 bottom-2 集合 (\mathcal B_{s,t})
* 若 (i\notin \mathcal B_{s,t})，则 (i) 被淘汰概率为 0
* 若 (i\in \mathcal B_{s,t})，评委更可能淘汰**评委分更低**的那位，比如：
  [
  \Pr(i\ \text{elim}\mid \mathcal B_{s,t})
  =\sigma!\big(\kappa,(J_{j,t}-J_{i,t})\big),\quad j=\mathcal B_{s,t}\setminus{i}.
  ]

### 3.3 观测层（似然）：把“真实淘汰者”绑回 (p_{i,t})

对一般“单人淘汰周”，给一个简单且可控的软似然（方便推断，也允许现实中的 tie/噪声）：
[
\Pr(E_{s,t}=i\mid S_{\cdot,t})
=\frac{\exp(\tau\cdot g(S_{i,t}))}{\sum_{k\in\mathcal A_{s,t}}\exp(\tau\cdot g(S_{k,t}))},
]
其中

* percent：(g(S)=-S)（越小越可能被淘汰）
* rank：(g(S)=+S)（越大越可能被淘汰）

多人淘汰周可用“选出最危险的 k 个”的近似（或按顺序抽样不放回）。

## 4) 问题一的输出怎么写成题目要的两类指标？

* **fan votes 输出**：给 (p_{i,t}) 的后验均值与区间；再给一个“等比例票数”
  [
  \hat F_{i,t}=\hat V_t\cdot \mathbb E[p_{i,t}\mid \text{data}]
  ]
  并明确说明 (\hat V_t) 是尺度选择（题面也承认票数不唯一）。

* **一致性（consistency）**：用后验均值（或 posterior predictive）回放规则，看每周淘汰命中率/每季命中率。

* **确定性（certainty）**：用后验区间宽度、后验标准差、或熵 (H(p_{\cdot,t}))；再比较这些量是否随选手/周显著不同。

---

## 5) 这套定义为什么“符合题设”，且避免你指出的问题？

* 题设要的是 **fan vote totals**，我们明确用 (F_{i,t}) 表示票数；同时用 (p_{i,t}=F_{i,t}/V_t) 做推断是因为题面已说明票数多解、示例票数是人为构造，绝对规模不可唯一确定。
* 对 percent 制度，决定淘汰的是**票占比**；对 rank 制度，决定淘汰的是**票的排序**（与占比排序等价）；因此用 (p_{i,t}) 推断并回推 (F_{i,t}) 完全贴合规则。
* 这也符合你们 summary.md 里强调的“先最小可行、再逐步加复杂度、并给不确定性与验证”的叙事要求。
